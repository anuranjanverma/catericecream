## 6. Live deployment

1. Back up live files and database.
2. Upload `dev/tools/content/meta-tags-20261112.php` (no plugin/theme code change).
3. `wp eval-file dev/tools/content/meta-tags-20261112.php dry-run report=/path/meta-dry.json`. Any **kept** line is a value already edited on live (e.g. by the SEO specialist): review it with the owner; the tool will not overwrite it.
4. `wp eval-file dev/tools/content/meta-tags-20261112.php report=/path/meta-applied.json`
5. `wp yoast index`, then purge caches (SiteGround and CDN).
6. View source (logged out) on the five URLs: title and description as in §1.
7. Search Console: request indexing for the five URLs (optional; Google updates snippets on its own schedule and may rewrite them).

## 7. Rollback

Every change is in the report (before → after). Revert by hand in the Yoast fields listed in §3, then `wp yoast index`. Locally: restore the backup SQL above.
