## Database and migrations

- **No schema migration.** The schema stays at v5. Saved quote progress uses existing storage: Flamingo inbound messages (marker meta `_cic_stage`, `_cic_activity`, `_cic_submitted_at`, `_cic_optional_at`, `_cic_draft_token` (HMAC only), `_cic_draft_rev`, `_cic_optional_rev`) and rows in the existing `{prefix}cic_submissions` table with `form = 'draft'` (both notification channels `skipped`, no Flamingo id, deleted after a day).
- **Historical inquiries are untouched:** no `_cic_stage` means "submitted".
- **New settings keys** have code defaults and are never written unless an admin saves them:
  - Enquiry settings: `reply_to` (empty) and `draft_retention_days` (0 = not set).
  - Layout: section `cities` (on, "Cities We Serve", 20 cities, "View all service areas").
  - Contact: `business_contact`.
  - Layout (group 5): `mobile.sticky_quote` (on); `main.show_call` now defaults to on, but a saved "off" stays off until the group 5 migration (or an admin) turns it on.
  - Populated live settings are not overwritten.
- **Prefixes:** every query uses `$wpdb->prefix` (`Store::table()`, `Tables::all()`, `$wpdb->postmeta`), and the per-draft MySQL lock name includes the prefix. This works with local `wp_` and live `itm_`.
- **Fixtures** are never reseeded: no tool touches the location tables.

## Form, storage, admin and notification behavior (what changed)

- **Form configuration:**
  - The CF7 quote form is still code-owned (`Forms::markup()`), now in two steps: details & favorites, then the event.
  - Notes, party theme and dietary details moved to the confirmation as optional details.
  - The flavor/topping question is no longer asked; its field stays in the code for historical records and the operator email.
  - The submit button reads "Request My Quote".
  - No CF7 admin changes are needed.
- **Storage:**
  - Step 1 Continue creates one Flamingo message marked Incomplete; later edits update it.
  - The CF7 submission completes the same message (subject, fields, consent, date set to submission time) and marks it Submitted. Without JavaScript, a new message is stored as before.
  - Draft-only REST routes: `POST /wp-json/cic/v1/quote-draft` and `/quote-draft/save`. They need the `X-CIC-Draft` header and same origin, are authorized by the HttpOnly draft cookie or the in-page key, and accept allowlisted, length-limited fields only. They are rate-limited and never submit.
- **Admin views:**
  - The Enquiries list shows Incomplete (with last activity) and Submitted pills, and has a "Completion" filter.
  - Incomplete inquiries are not counted as New.
  - The detail screen has a Completion box (status, last activity, submitted time, optional details updated). The CSV export has a `stage` column.
  - Flamingo's own inbound screen also lists drafts, with the subject "Quote request (not yet submitted)".
- **Notifications:**
  - Unchanged: one operator notification and one acknowledgement when the request is submitted.
  - None for incomplete inquiries; no abandonment emails, calls or reminders. Optional details never resend anything.
  - The notification's link opens the same inquiry ID.
